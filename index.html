🎓 How Does It Work? (Exhibition Walkthrough)
When you draw on the interactive canvas, the system tracks continuous movement inside a 2D Cartesian grid measuring 600 × 400 pixels. The horizontal axis represents X, and the vertical axis represents Y with the center origin marked at (300, 200).
Every movement of your mouse or finger is sampled at up to 60 times per second into discrete mathematical coordinates: (x₁, y₁), (x₂, y₂), (x₃, y₃).... Jitter filtering removes micro-movements so each point represents an intentional musical landmark.
The math engine computes:
  • Euclidean Distance: d = √((x₂ - x₁)² + (y₂ - y₁)²) for segment path length.
  • Zero-Division Safe Slope: m = (y₂ - y₁) / (x₂ - x₁) measuring line steepness.
  • Direction Angle: θ = atan2(Δy, Δx) capturing line curvature.
  • Bilateral Symmetry: Compares the reflection distance error across the vertical center axis X = 300.
Geometry is mapped into the C Major Pentatonic Scale (C, D, E, G, A). Pentatonic scales contain no harsh dissonant intervals, ensuring that any shape you draw naturally harmonizes. X-position chooses pitch, Y-position controls tempo, distance controls note duration, and slope modulates instrument timbre.
The browser's Web Audio API generates a clean analog synthesizer and rhythm engine. Sine and triangle oscillators connect directly through gain stages into your headphones, with live pink oscilloscope monitoring.
